# Osborn PA 工作台 · 使用指南

## 安装

1. 打开要使用的多维表格，点右上角「插件」。
2. 在插件市场搜索「Osborn PA 工作台」，点添加。
3. 第一次打开时，如果表格里还没有工作台需要的数据表，点「一键创建数据表」（需要多维表格管理权限），大约一分钟完成。已有的表和数据不会被改动。

## 第一次使用

1. 点工作台顶部的「加入」。第一个加入的人自动成为管理员，之后的人是成员。没加入的人只能查看。
2. 在目标区输入一个目标名称，选「今日」或「本周」，点「添加」。

## 排时间（三种方式）

- **拖进日历**：把右侧的目标拖到左侧日历的某个时间格。
- **拖动改期**：在日历里拖动已有的时间块，放到新的时间。
- **填时间**：点目标旁的「安排…」，填日期、开始和结束时间，点保存。

排好的时间块点一下，可以选「完成」或「取消安排」。

## 看目标

- 「目标看板」按 Inbox、今日、明日、本周、下周、本月等分组。
- 「轻重缓急」按重要和紧急程度排序。
- 勾选「私有」的目标在工作台里只有自己能看到。

## 常见问题

**为什么显示“未加入（只读）”？**
点顶部的「加入」即可。如果显示“成员已停用”，请联系管理员。

**两个人同时改了同一个时间块会怎样？**
后保存的一方会收到“版本冲突，未覆盖”，刷新后看到最新时间再改。

**“私有”目标别人真的看不到吗？**
只在工作台里看不到。能直接打开这张多维表格的人，在表格里仍能看到所有记录。

**数据会传到别的地方吗？**
不会。所有数据只写在当前多维表格里。
