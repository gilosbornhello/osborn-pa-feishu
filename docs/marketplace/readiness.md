# 上架准备度（2026-11-04）

依据：多维表格开发者中心“商品配置”页面实际字段，以及官方《Marketplace 开发者中心指南》（开发者中心左下角 Developer Guide）。

## 官方流程要点

1. **开发者入驻**：企业管理员在 `https://<租户>/base/developer/onboarding` 申请，同意开发者服务协议，提交企业资料：企业名称、营业执照（有效期半年以上）、统一社会信用代码、法人及联系方式、法人身份证、企业客服电话、企业介绍文档、盖公章的授权证明、市场展示名称和头像、联系地址、联系人和电话。3 个工作日内审核。
2. **收款账户**：只有付费商品需要开通。本插件计划免费，不需要。
3. **创建商品**：类型选“插件”。插件子类型只有：应用模式插件、字段捷径（FaaS／公式）、边栏插件、连接器、仪表盘插件、节点捷径。**没有数据表视图**。
4. **提交代码**：填 GitHub 仓库地址，飞书做安全审核并部署。可用公开仓库，或把私有仓库授权给 `bitable-open@bytedance.com`。
5. **可见范围**：私有／当前组织／公开。
6. **发布**：点“发布”进入平台审核；每周二、周四集中审核上架。
