### 详情介绍（≤3000）

```
Osborn PA 工作台把“要做的目标”和“什么时候做”放进同一个界面：一边是一周日历，一边是目标看板；在边栏里日历在上、目标在下。

【它解决什么】
目标写在一张表里，日程排在另一个地方，经常对不上：重要的事一直没排进时间，排了的又找不到对应的目标。工作台让你直接把目标拖进日历，排好的时间块和目标始终关联在一起。

【三种排时间的方式，各管各的】
1. 把目标拖进日历的时间格，生成一个时间块。
2. 在日历里拖动已有的时间块，改到别的时间。
3. 点目标旁的“安排…”，填日期和开始、结束时间。
排好的块可以点开“完成”或“取消安排”。

【目标看板与轻重缓急】
目标按 Inbox、今日、本周、本月等时间段分组；也可以切到“轻重缓急”，按重要和紧急程度排序。在工作台里可以直接新建目标，负责人默认是自己。

【多人一起用】
每个人看到的是自己负责或参与的目标；同事的时间块只显示为“忙碌”，不显示标题。两个人同时改同一个时间块时会提示冲突，不会悄悄覆盖对方的修改。

【数据在哪里】
所有目标和时间安排都保存在你自己的多维表格里，可以随时用表格、筛选、仪表盘查看和导出。插件不连接任何外部服务器，不收集数据。

【请注意】
“私有”目标只在工作台里对别人隐藏。能直接打开这张多维表格的人，在表格里仍能看到所有记录。需要严格隔离时，请用多维表格的高级权限控制谁能打开哪些记录。
```
