### 2026-11-03 补记：插件内要求 cookies → 页面改为公开
- 现象：把妙搭页面作为自定义插件加入测试 Base 后，插件内提示需要允许 cookies（桌面客户端与浏览器都出现）。判断：页面设为“需登录”，在多维表格插件框架中属于跨站嵌入，登录 cookie 被当作第三方 cookie 拦截。
- 处理（用户在对话中同意）：访问范围改为**公开、不要求登录**（`scope=All`，`require_login=false`）。理由：页面只含静态代码（与公开仓库相同）、不含数据；数据读写走 Base JS SDK，以使用者自己的 Base 权限进行。代价：任何拿到链接的人都能打开空壳页面与合成样例。不应要求每个使用者修改浏览器 cookie 设置。
- 同时发现并修复两个妙搭托管特性（`tools/build-hosted.mjs`）：

  - 脚本被 302 到带签名的 CDN 地址，ES 模块的相对 import 落到无签名地址返回 403 → 新增零依赖打包器 `tools/bundle-esm.mjs`（只支持本仓库用到的导入导出形式，遇到其他形式直接报错）及 3 项测试，工作台以单文件发布。
